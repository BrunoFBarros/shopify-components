# Hero Full Bleed

Makes your hero image fill the entire screen — no cropping, no gaps.
Transparent header included.

![Before / After](./preview.png)

---

## What it does

- Hero image fills 100% of the screen height
- Image slides behind the header — no white gap at the top
- Full image always visible — no cropping on any screen size
- Header becomes transparent automatically

---

## Installation

**1. Go to your Shopify admin**
Online Store → Themes → Edit code → `theme.liquid`

**2. Find the opening `<head>` tag**

**3. Paste this code just before it**
```css
/* copy from snippet.css */
```

**4. Save**

**5. In the theme editor**
Go to Header → enable **Transparent background**

---

## Compatibility

✓ Tested on Shopify Horizon OS2
✓ Works with any hero image
