# Shopify Components

Free, copy-paste Shopify components for Horizon OS2.
No apps. No subscriptions. No bullshit.

---

## How to use

Each component has its own folder with a README explaining what it does and how to install it, plus a code snippet ready to copy and paste.

No build tools. No dependencies. Just copy, paste, save.

---

## Compatibility

Tested on **Shopify Horizon OS2**.
May work on other themes — results may vary.
